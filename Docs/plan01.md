
# 项目结构重构与功能升级任务说明

你需要对现有健康平台项目进行一次结构性升级，包含模块重命名、功能扩展、UI布局调整、数据结构适配。请按以下要求修改，并保证代码结构清晰、可扩展。



## 一、健康资讯 → 社区模块改造

### 1. 模块重命名

* 将「健康资讯」模块整体改为「社区」
* 修改所有路由、导航名称、页面标题、接口命名

### 2. 布局改造（采用十字架布局）

页面结构：

* 顶部：搜索栏
* 左侧边栏：

  * 推荐
  * 关注
  * 热门
  * 分类标签
  * 我的发帖
* 中间：帖子流（卡片式）
* 右侧：热门话题 / 活跃用户 / 公告

### 3. 搜索功能

新增搜索功能，要求：

* 支持模糊搜索（LIKE）
* 支持精准搜索（标题精确匹配）
* 支持按标签筛选
* 搜索结果分页展示

后端新增：

* 搜索接口
* 标签字段
* 建立索引优化查询性能

数据模型新增或调整：

* Post
* Comment
* Like
* Favorite
* Tag
* UserFollow

## 二、健康库 → 探索模块升级

### 1. 模块重命名

* 将「健康库」改为「探索」
* 修改所有相关路由与引用

### 2. 定位升级

不再只包含训练计划，扩展为健康模块中心。

### 3. 布局结构（十字架布局）

* 顶部：模块标题 + 搜索栏
* 左侧：健康模块导航
* 主区域：模块卡片展示

### 4. 设计健康模块体系

至少包含：

* 运动训练
* 饮食管理
* 睡眠管理
* 体重管理
* 心率血压记录
* 心理健康

要求：

* 模块结构可扩展
* 模块采用统一组件结构
* 支持后期新增模块

## 三、我的数据大盘 → 摘要模块重构

### 1. 重命名

* 将「我的数据大盘」改为「摘要」

### 2. 页面结构重构

结构如下：

#### 顶部：置顶三模块区

* 默认显示3个健康数据模块
* 支持用户自由选择展示的模块
* 支持拖拽排序或编辑
* 配置持久化保存

#### 中部：趋势展示区

* 一个折线图组件
* 支持：

  * 展示所有趋势
  * 单选某一指标趋势
  * 可多选对比

#### 底部：全部模块区

* 展示所有健康模块组件
* 组件可点击进入详细页
